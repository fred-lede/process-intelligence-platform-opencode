# v0.8.0 Release Notes

## Data readiness before modeling

- Added `data/readiness` engine API for all confirmed input/output columns.
- Reports numeric validity, missing values, uniqueness, summary statistics, candidate distributions, AIC/BIC/KS and severity.
- Added readiness overview and status chart to the Data Import page.
- Blocks model fitting when readiness contains critical issues.
- Passes readiness summaries into the AI assistant and persists readiness snapshots in reports.
- Report lists expose the readiness status used at generation time.

## Verification

- Readiness fixture tests pass in `engine/tests/test_readiness.py`.
- Existing main-handler tests pass.
- Python compilation and `npm run build` pass.

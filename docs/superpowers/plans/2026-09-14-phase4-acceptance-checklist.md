# Phase 4 時間序列工程閉環驗收清單

## 目的

確認時間序列模型從候選比較、驗證閘門、人工核准到序列風險模擬的流程具備可追溯條件，並與既有 DOE、AI、混合模型及報告流程相容。

## 驗收項目

- [x] 時間排序、缺值、重複時間與不規則間隔檢查。
- [x] 按時間切分的固定預測期與觀測特徵留出評估。
- [x] Naive、季節性 Naive、ARIMA、動態迴歸、時間特徵樹模型與混合模型比較。
- [x] 資料洩漏狀態、訓練／測試範圍及評估協定顯示於結果中。
- [x] Walk-forward／rolling-origin 驗證與預測區間覆蓋率 Gate。
- [x] 候選模型需經 Gate、人工審查與核准後才能進入正式使用。
- [x] 核准模型可保存版本、估計器回放 metadata 與訓練資料範圍。
- [x] 序列情境模擬採遞迴預測；禁止直接套用獨立抽樣 Monte Carlo。
- [x] 隨機序列模擬支援 seed、模擬次數、殘差來源與區間校準紀錄。
- [x] 既有 DOE、一般 AI、Copula、報告與模型中心流程維持相容。

## 尚待真實資料確認

測試資料只能驗證流程與介面契約，不能代表實際製程的預測準確度或區間覆蓋率。正式核准前仍需使用足夠長度、跨批次／機台且時間順序正確的歷史資料，重新執行 Gate，並由工程人員確認少量 DOE 或實驗結果。

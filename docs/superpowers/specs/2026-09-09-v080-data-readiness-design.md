# v0.8.0 資料來源健檢與分布診斷設計

## 目標

在資料匯入完成後、探索分析與模型配適前，自動檢查所有 input/output 欄位，提供分布配適、資料品質與可視化結果，協助判斷資料是否適合進入後續分析。

## 範圍

- 沿用既有資料匯入與品質檢查結果。
- 自動對所有數值 input/output 執行候選分布配適與摘要統計。
- 顯示缺失、重複、常數、離群、型別與樣本對齊問題。
- 提供每欄位診斷表、分布圖與嚴重度（阻擋／警告／資訊）。
- 保存診斷快照與資料集版本，供 AI、報告及模型配適前 Gate 使用。

## 非目標

- 不由分布結果自動決定或替使用者建立模型。
- 不取代 SPC、時間序列、GRR 或既有探索分析。
- 不將分布配適視為因果關係或母體分布證明。

## 流程

`資料匯入 → 欄位角色確認 → 資料來源健檢 → 分布與品質可視化 → 建模前 Gate → 探索／模型配適`

## 判定規則

- 欄位型別不適合、沒有有效數值或 input/output 樣本無法對齊：阻擋。
- 缺失率、常數欄位、嚴重離群、分布配適無明確最佳者：警告。
- 正常完成且有可比較配適結果：資訊。
- 分布僅作為抽樣與後續方法選擇依據；模型仍需交叉驗證與工程確認。

## 介面契約

診斷結果至少包含 dataset_id、欄位名稱與角色、有效／缺失／唯一值數、min/max/mean/std、候選分布及 AIC/BIC/KS、問題清單與 overall_status。結果必須可由 AI 上下文與報告產生器引用。

## 驗證

- 匯入正常模板與含缺失、常數、文字混合及錯位資料的 fixture。
- 驗證每欄位結果、嚴重度、圖表與模型配適前 Gate 一致。
- 驗證 v0.8.0 版本同步與既有匯入／探索／模型測試不回歸。

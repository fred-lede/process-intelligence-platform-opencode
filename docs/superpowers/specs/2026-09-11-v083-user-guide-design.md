# v0.8.3 使用說明設計

## 目標

在系統設定下方加入「使用說明」入口，以目前中央頁面與子功能顯示統計原理、公式、圖表判讀、限制與工程建議。

## 範圍

- 支援繁體中文、英文、西班牙文（es-MX）。
- 說明視窗不離開目前頁面，並依目前頁籤切換內容。
- 涵蓋資料匯入、SPC、探索分析四個子頁、模型中心、蒙地卡羅、驗證實驗、報告與版本。
- 說明內容與 AI 助手可見的分析語意一致，但不新增 AI 行為。

## 介面與資料流

導航入口開啟共用 GuideModal；App 目前 active tab 與子頁籤作為 guide key，從本地化內容表取得標題、目的、原理、公式、判讀、限制與建議。沒有專用內容時顯示通用頁面說明，不阻塞主畫面。

## 非目標

- 不新增統計計算或修改既有分析結果。
- 不新增簡中、日文或泰文翻譯。
- 不取代頁面現有摘要與圖表。

## 驗收條件

1. 導航可開啟與關閉說明視窗。
2. 在主要頁面與子頁籤切換時，說明標題與內容對應正確。
3. 三種語言沒有遺漏 key，公式與限制可讀。
4. 建置與既有測試通過。

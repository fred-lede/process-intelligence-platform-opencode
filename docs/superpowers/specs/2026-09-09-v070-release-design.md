# v0.7.0 Release Design

## 目標

在 v0.6.0 多層級資料與追溯基礎上，提升報告一致性、AI 助手可靠性與跨層級分析體驗。

## 範圍

- 報告中心：HTML、PDF、Excel 內容與 metadata 一致，支援歷史報告檢視與重新匯出。
- AI 助手：provider 錯誤、timeout 與資料集恢復提示更清楚，操作草案引用可追溯。
- 多層級分析：產品、Lot、機台、站點與子群組的切換、比較與 drill-down。
- 部署品質：跨平台打包檢查與版本同步 CI 驗證。

## 非目標

- 不引入 MES／雲端資料庫整合。
- 不改變既有 CSV／Excel 匯入格式與 v0.6.0 專案檔相容性。
